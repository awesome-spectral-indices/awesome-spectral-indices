## Formula

```
(RE3 - R) / (RE1 / RE2)
```

### Bands

- `RE3`: Red Edge 3.
- `R`: Red.
- `RE1`: Red Edge 1.
- `RE2`: Red Edge 2.

No constants are used in this index.

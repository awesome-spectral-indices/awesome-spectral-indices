## Formula

```
(N-(S2+T))/(N+(S2+T))
```

### Bands

- `N`: Near-Infrared (NIR).
- `S2`: Short-wave Infrared (SWIR) 2.
- `T`: Thermal Infrared.

### Constants

No constants are used in this index.

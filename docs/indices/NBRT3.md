## Formula

```
((N - (T / 10000.0)) - S2) / ((N - (T / 10000.0)) + S2)
```

### Bands

- `N`: Near-Infrared (NIR).
- `T`: Thermal Infrared.
- `S2`: Short-wave Infrared (SWIR) 2.

### Constants

No constants are used in this index.

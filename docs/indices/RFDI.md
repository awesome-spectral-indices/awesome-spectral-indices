## Formula

```
(HH - HV)/(HH + HV)
```

### Bands

- `HH`: Horizontal transmit, horizontal receive radar polarization.
- `HV`: Horizontal transmit, vertical receive radar polarization.

### Constants

No constants are used in this index.

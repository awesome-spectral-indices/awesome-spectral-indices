## Formula

```
(S2 - N2 - G - B)/(S2 + N2 + G + B)
```

### Bands

- `S2`: Short-wave Infrared (SWIR) 2.
- `N2`: Near-Infrared (NIR) 2.
- `G`: Green.
- `B`: Blue.

### Constants

No constants are used in this index.

## Formula

```
(N - T/10000.0)/(N + T/10000.0)
```

### Classification

- Application domain: `Burn`
- Sensing modalities: `Multispectral`, `Thermal`

### Bands

- `N`: Near-Infrared (NIR).
- `T`: Thermal Infrared.

### Polarizations

No radar polarizations are used in this index.

### Constants

No constants are used in this index.

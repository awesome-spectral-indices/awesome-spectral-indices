## Formula

```
((N - B)/(N + B)) * N
```

### Classification

- Application domain: `Vegetation`
- Sensing modalities: `Multispectral`

### Bands

- `N`: Near-Infrared (NIR).
- `B`: Blue.

### Polarizations

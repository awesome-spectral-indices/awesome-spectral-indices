## Formula

```
((N - R) / (N + R)) * N * PAR
```

### Bands

- `N`: Near-Infrared (NIR).
- `R`: Red.

### Constants

No constants are used in this index.

### External Variables

- `PAR`: Photosynthetically Active Radiation.

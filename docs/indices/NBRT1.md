## Formula

```
(N - (S2 * T / 10000.0)) / (N + (S2 * T / 10000.0))
```

### Bands

- `N`: Near-Infrared (NIR).
- `S2`: Short-wave Infrared (SWIR) 2.
- `T`: Thermal Infrared.

### Constants

No constants are used in this index.

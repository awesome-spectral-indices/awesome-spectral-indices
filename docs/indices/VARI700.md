## Formula

```
(RE1 - 1.7 * R + 0.7 * B) / (RE1 + 1.3 * R - 1.3 * B)
```

### Bands

- `RE1`: Red Edge 1.
- `R`: Red.
- `B`: Blue.

### Constants

No constants are used in this index.

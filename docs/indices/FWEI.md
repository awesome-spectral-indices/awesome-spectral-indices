## Formula

```
(((B + G + R) / 3.0) - N)/(((B + G + R) / 3.0) + N)
```

### Bands

- `B`: Blue.
- `G`: Green.
- `R`: Red.
- `N`: Near-Infrared (NIR).

### Constants

No constants are used in this index.

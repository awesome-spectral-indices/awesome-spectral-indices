## Formula

```
((B - T1)/(B + T1)) - ((N - R)/(N + R))
```

### Bands

- `B`: Blue.
- `T1`: Thermal Infrared 1.
- `N`: Near-Infrared (NIR).
- `R`: Red.

### Constants

No constants are used in this index.

## Formula

```
(N + 2.0 * S1) / (B + G + R)
```

### Bands

- `N`: Near-Infrared (NIR).
- `S1`: Short-wave Infrared (SWIR) 1.
- `B`: Blue.
- `G`: Green.
- `R`: Red.

### Constants

No constants are used in this index.

## Formula

```
0.36 * (G + R + N) - (((B + S2)/G) + S1)
```

### Bands

- `G`: Green.
- `R`: Red.
- `N`: Near-Infrared (NIR).
- `B`: Blue.
- `S2`: Short-wave Infrared (SWIR) 2.
- `S1`: Short-wave Infrared (SWIR) 1.

### Constants

No constants are used in this index.

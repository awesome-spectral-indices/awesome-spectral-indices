## Formula

```
(VV + VH)/2.0 ** 0.5
```

### Bands

- `VV`: Vertical transmit, vertical receive radar polarization.
- `VH`: Vertical transmit, horizontal receive radar polarization.

### Constants

No constants are used in this index.

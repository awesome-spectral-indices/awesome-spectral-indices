## Formula

```
((G - S1)*(S2 - R))/((G + S1)*(S2 + R))
```

### Classification

- Application domain: `Urban`
- Sensing modalities: `Multispectral`

### Bands

- `G`: Green.
- `S1`: Short-wave Infrared (SWIR) 1.
- `S2`: Short-wave Infrared (SWIR) 2.
- `R`: Red.

### Polarizations

No radar polarizations are used in this index.

### Constants

No constants are used in this index.
